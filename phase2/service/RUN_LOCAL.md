# Run the released Real-Abshar service locally

These instructions apply to the **large Service Release ZIP generated by the Kaggle notebook**,
not the small Service Kit ZIP or the small review ZIP. Keep the release ZIP privately through
the final presentation. It contains all three ONNX graphs and their processor/configuration files.
After dependencies are installed, inference needs no Kaggle account, W&B key or network download.

The notebook tests the actual service on Kaggle Linux CPU through real loopback HTTP requests.
Windows commands below are a portable launch route; Windows latency is not measured by the
Kaggle benchmark. The notebook shuts its temporary server down after collecting evidence.
Do not describe that temporary loopback endpoint as a publicly hosted service.

## Environment

Use Python3.13, Torch2.11.x CPU and torchvision0.26.x CPU. Extract the Service Release ZIP into
one folder and open a terminal in it. Create a dedicated environment before installing packages.

Windows PowerShell:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements_serve.txt
.\.venv\Scripts\python.exe serve.py --release . --port 8000
```

Linux shell:

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -r requirements_serve.txt
.venv/bin/python serve.py --release . --port 8000
```

The recorded reference environment is Kaggle Linux x86_64. Use that environment for the
reported benchmark; a local Windows run has its own hardware and timing conditions.

Once startup succeeds, open **http://127.0.0.1:8000/** in a browser. The image form displays
the model label, editing-region boxes, native-size predicted mask, area estimate and review
decision. **http://127.0.0.1:8000/docs** exposes the generated API documentation.

## API examples

```bash
curl http://127.0.0.1:8000/health
curl -X POST -F "file=@example.png" http://127.0.0.1:8000/predict
```

On Windows PowerShell use `curl.exe` when `curl` is an alias:

```powershell
curl.exe -X POST -F "file=@example.png" http://127.0.0.1:8000/predict
```

Request: multipart form with one field named `file`; decoded JPEG/PNG/WebP, one still frame,
file≤10MiB, decoded pixels≤12,000,000, each side≥16 pixels. EXIF transpose precedes RGB conversion.
Filename and declared MIME are not used to establish the decoded format.

Response: JSON with oriented native dimensions, global Real/Fake label and uncalibrated fake
score, native-pixel xyxy boxes, a base64 PNG mask containing label values0/1 (1=edited), native
foreground-pixel count and edited-area fraction, explicit review reasons, release identifier
and per-stage timings. The upload image is not returned. The service closes the uploaded
temporary file and does not retain user images/predictions.

Errors: empty/corrupt image400; unsupported/animated format415; too-small image422;
file/pixel limit413; missing upload422; inference failure500 with no authenticity decision.

## Settings and startup checks

The service reads `manifest.json`. It verifies its frozen checksum, source/configuration hashes,
the three model graph hashes, ONNX input/output shapes/types, runtime versions and a synthetic
64×64 RGB smoke input. A changed manifest/source/model is rejected rather than silently served.

Model inputs: classifier224×224 using the saved torchvision-backed Hugging Face processor;
detector640×640 with OpenCV linear resize/114-padding; segmenter640×640 with PIL bilinear
resize/black-padding and ImageNet normalization. Native-size mask restoration crops padding,
resizes probabilities, then thresholds. Segmentation runs even when the other models return no flag.

Read the actual thresholds in `manifest.json` and the validation selection in `decision_policy.json`.
Global fake threshold0.5; detector strict confidence>0.35, NMS0.45, max50; segmentation pixel
threshold≥0.5, no morphology. The validation-selected review rule combines any global flag,
any selected box, or an edited-area fraction above its selected minimum. It changes the review
decision only; small mask pixels remain available in the response/UI.

One server process serializes inference requests. The benchmark uses concurrency1, batch1, FP32,
CPUExecutionProvider with two intra-operation threads and one inter-operation thread.
Stop the local server with Ctrl+C. Keep the release and these run instructions available
through the final presentation. Do not put model weights, dataset images/masks, private
per-image evidence or credentials in the public repository.
